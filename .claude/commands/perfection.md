# Perfection Master Workflow

The user’s request is:

$ARGUMENTS

Follow this process:

1. **Understand**
   - Restate the goal in one or two sentences.
   - Identify the deliverable, audience, constraints, and success criteria.
   - Ask a clarifying question only if the task cannot proceed safely or correctly.

2. **Select workflow**
   - Choose the most relevant workflow, agent, skill, or command already available in this repository.
   - Prefer existing Perfection capabilities over creating new ones.
   - If a new reusable workflow is needed, propose it before creating it.

3. **Research**
   - Research only what is needed.
   - Use reliable sources.
   - Separate facts from assumptions.

4. **Plan**
   - Produce a concise step-by-step plan.
   - Identify files, assets, tools, approvals, and risks.
   - Do not begin irreversible external actions without explicit approval.

5. **Execute**
   - Complete the task using the selected workflow.
   - Keep the user informed with clear, non-technical updates.
   - Preserve existing business rules, branding, and quality standards.

6. **Verify**
   - Check completeness, accuracy, consistency, and usability.
   - Identify errors, missing information, and improvement opportunities.
   - Test or validate the result where possible.

7. **Report**
   - Provide:
     - What was completed
     - Where the result is located
     - Key decisions made
     - Assumptions
     - Risks or limitations
     - Recommended next steps
   - Ask for approval before publishing, deploying, sending, or making any irreversible change.
